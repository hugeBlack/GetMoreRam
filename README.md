⚡ Get More Ram (ram-6itoon)
 
Enable "Increased Memory Limit" for your sideloaded apps — without Xcode!
 
A simple, lightweight wrapper app that lets you boost the memory limit of your sideloaded iOS apps. Forked from hugeBlack/GetMoreRam with major fixes, improvements, and Persian language support. 
 
✨ Features
• ✅ Enable Increased Memory Limit for sideloaded apps
• 🚫 No Xcode required — works entirely on-device
• 🛠️ Fixed -80045 and 503 Service Temporarily Unavailable errors
• 🌐 Persian (فارسی) language support
• 🔄 Updated default Anisette server to https://ani.jkcoxson.com (same approach as iloader)
• 📱 Compatible with SideStore, AltStore, iloader, and other sideloading tools 
 
📥 How to Use
1. Sideload this app (using SideStore / AltStore / iloader / etc.)
2. Open Settings and sign in with the same Apple ID you used to sign the target app
3. Go to the App IDs page
4. Tap Refresh
5. Tap the app you want to enable Increased Memory Limit for
6. Tap Add Increased Memory Limit
7. Reinstall the app from SideStore / AltStore
8. ✅ Done! Check if you now have Increased Memory Limit enabled 
 
🔧 Troubleshooting
 
If login still fails:
• Go to Settings → Clean Up Keychain
• Change the Anisette Server URL if needed
Recommended: https://ani.jkcoxson.com or https://ani2.stikstore.app
• Force-close the app and try again
• Or import your SideStore account (export from SideStore settings)
